## 📌 About Textify AI

Textify AI is a Python-powered web application that transforms ordinary digital text into handwritten-style pages.

Designed for simplicity and customization, it lets users choose handwriting fonts, paper layouts, ink colors, page sizes, and spacing before previewing and exporting their documents as PDFs.

🌐 **Live Application:** https://textifyai.streamlit.app/

## ✨ Features

- ✍️ **Text-to-Handwriting:** Transform typed text into handwritten-style pages.
- 🖋️ **Handwriting Fonts:** Choose from the available handwriting-style fonts.
- 📄 **Multiple Page Sizes:** Select A4, Letter, or A5.
- 📐 **Flexible Layouts:** Customize page orientation and margins.
- 📓 **Paper Styles:** Choose from available paper backgrounds and ruled layouts.
- 🎨 **Ink Colors:** Personalize your writing with different ink colors.
- 📏 **Spacing Controls:** Adjust line spacing for your preferred appearance.
- 👀 **Page Preview:** Review generated pages before exporting.
- 📥 **PDF Download:** Save your completed document as a PDF.
- 📱 **Responsive Interface:** Access the application on desktop and mobile screens.

## ⚡ Getting Started

Run Textify AI locally using the following steps.

### 1. Clone the repository

```bash
git clone https://github.com/codewithMeesum/Textify-AI-.git
cd Textify-AI-
```

*Replace the repository URL or directory name if your actual GitHub repository uses a different name.*

### 2. Create a virtual environment

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```

**macOS / Linux**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Launch the application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal to use the application.

## 📖 How to Use

1. Open [Textify AI](https://textifyai.streamlit.app/).
2. Type or paste your text.
3. Select your handwriting font and ink color.
4. Customize paper style, page size, orientation, margins, and spacing.
5. Generate and preview your pages.
6. Download your document as a PDF.
